Материалы и методы и инструменты исследования, теоретическая база

Материалы: учебники Олифера и Таненбаума, стандарт IEEE 802.12

Методы: анализ, сравнительный анализ, систематизация

Теоретическая база:

  1. уровни OSI: физический и канальный (MAC)
  2. случайный доступ CSMA/CD — коллизии
  3. детерминированный доступ — маркер или опрос, коллизий нет

Содержание исследования

Предлагаемое решение задач с обоснованием

Подход: последовательный, по уровням модели OSI

Порядок: история → архитектура → метод доступа → физический уровень → сравнение

Обоснование: сравнение по единым критериям позволяет проверить гипотезу

Основные этапы(1-3)

Этап 1. История: HP и AT&T, 1993–1995, стандарт IEEE 802.12

Этап 2. Архитектура:

звезда / иерархическая звезда до 3 уровней

концентратор управляет доступом, кадр — только получателю

Этап 3. Demand Priority:

узел запрашивает, концентратор разрешает по очереди

два приоритета, коллизий нет

Основные этапы(4-5)

Этап 4. Физический уровень:

витая пара кат. 3, 4 пары

квартетное кодирование 5B/6B + NRZ

4 × 25 = 100 Мбит/с, полудуплекс

Этап 5. Сравнение с Fast Ethernet:

нет коллизий, есть приоритеты, кадры Ethernet и Token Ring

но нет совместимости с 10BASE-T

Анализ и практическая значимость достигнутых результатов

Почему победил Fast Ethernet: совместимость с Ethernet и автосогласование 10/100, дешёвое оборудование многих производителей, массовый кабель категории 5, коммутаторы и полный дуплекс убрали коллизии, дальнейшее развитие — Gigabit Ethernet

Достоинства 100VG-AnyLAN: нет коллизий, приоритеты, два формата кадров, старый кабель

Недостатки: несовместимость, дорогие концентраторы, мало производителей, полудуплекс

Общее заключение и выводы

Выводы:

  1. 100VG-AnyLAN — альтернатива Fast Ethernet с детерминированным доступом

  2. Demand Priority исключает коллизии и даёт малую задержку для голоса и видео

  3. Квартетное кодирование позволило 100 Мбит/с по кабелю категории 3

  4. Технология проиграла из-за несовместимости, цены и появления коммутаторов

  5. Её идеи сохранились в современных коммутируемых сетях Ethernet

Итог: гипотеза подтвердилась — техническое превосходство не гарантирует успеха
