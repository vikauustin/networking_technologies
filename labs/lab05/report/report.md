# Цель работы

Получение навыков настройки службы DHCP на сетевом оборудовании для распределения адресов IPv4 и IPv6.

# Задание

1. Настроить на маршрутизаторе vyos dhcp-сервер для распределения адресов ipv4 из диапазона 10.0.0.2-10.0.0253, настроить получение адреса по dhcp на узле pc1 и исследовать паакеты dhcp
2. Настроить на интерфейсе eth1 маршруттизатора dhcpv6 без отслеживания состояния, а на интерфейсе eth2-dhcpv6 с отслеживанием состояния. Проверить получение настроек клиентами

# Теоретическое введение
 
Протокол DHCP позволяет устройствам автоматически получать IP-адрес и другие параметры сети: шлюз по умолчанию, маску подсети, адреса DNS-серверов и доменное имя [@rfc2131]. Он работает по модели «клиент–сервер» поверх UDP (сервер принимает сообщения на порт 67, клиент — на порт 68). Адрес выдаётся на определённое время (аренда) в четыре шага: клиент отправляет широковещательный запрос Discover, сервер предлагает адрес сообщением Offer, клиент соглашается сообщением Request, а сервер подтверждает аренду сообщением ACK.
 
В сетях IPv6 адрес можно настроить без DHCP с помощью SLAAC: маршрутизатор объявляет префикс сети в сообщениях Router Advertisement, а клиент сам формирует адрес [@rfc4862; @rfc4861]. DHCPv6 нужен, когда требуются дополнительные параметры (например адрес DNS-сервера) или контроль над выдачей адресов [@rfc8415]. Режим работы определяют флаги в объявлении маршрутизатора: при флаге other-config клиент получает адрес автоматически, а остальные параметры запрашивает у сервера (режим без отслеживания состояния), а при флаге managed сервер выдаёт адрес и отслеживает его аренду (режим с отслеживанием состояния). Оборудование настраивалось на маршрутизаторе VyOS в эмуляторе GNS3 [@vyos_docs; @gns3_docs; @korolkova_net].

Интерфейсу eth0 назначен адрес 10.0.0.1/24. Настроен DHCP-сервер: общая сеть vvustinova с доменом vvustinova.net и DNS-сервером 10.0.0.1, подсеть 10.0.0.0/24 со шлюзом по умолчанию 10.0.0.1 и диапазон адресов, начинающийся с 10.0.0.2 (рис. [-@fig:004]).

# Выводы
 
В ходе работы получены навыки настройки службы DHCP на маршрутизаторе VyOS для распределения адресов IPv4 и IPv6. Клиент PC1 получил адрес, шлюз и DNS-сервер от DHCP-сервера, а получение адреса прослеживается по пакетам Discover, Offer, Request и ACK. При настройке DHCPv6 без отслеживания состояния адрес формируется автоматически, а сервер аренду не ведёт. При настройке с отслеживанием состояния сервер выдаёт клиенту адрес из диапазона, передаёт параметры DNS и фиксирует аренду.
