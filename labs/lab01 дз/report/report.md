# Цель работы

Изучение методов кодирования и модуляции сигналов с помощью высокоуровнего языка программирования Octave. Определение спектра и параметров
сигнала. Демонстрация принципов модуляции сигнала на примере аналоговой амплитудной модуляции. Исследование свойства самосинхронизации сигнала

# Задание

Построить графики функций в Octave с использованием функции plot и экспортировать их в файлы .eps и .png. Разработать код m-файла для построения графиков меандра с различным количеством гармоник. Найти спектры синусоидальных сигналов и их суммы с помощью быстрого преобразования Фурье. Продемонстрировать принципы амплитудной модуляции. Получить кодированные сигналы для нескольких кодов, проверить свойства самосинхронизируемости и получить спектры.

# Выводы

В ходе работы были изучены методы кодирования и модуляции сигналов с помощью языка Octave. Освоены построение графиков функций, разложение импульсного сигнала в частичный ряд Фурье, нахождение спектров сигналов через быстрое преобразование Фурье. Продемонстрированы принципы амплитудной модуляции и исследовано свойство самосинхронизации различных кодов. Установлено, что униполярный и NRZ-коды не обладают самосинхронизацией, а AMI, RZ и манчестерские коды — обладают.
